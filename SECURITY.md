# Security Policy

## Supported version

Security fixes are applied to the latest version on the `main` branch.

## Reporting a vulnerability

Do not open a public issue for a suspected vulnerability or include credentials, tokens, database dumps, or proof-of-concept exploits in public discussions.

Report the issue privately to the repository owner. Include a clear description, affected route or component, reproduction steps, and impact. The maintainer will acknowledge the report, assess it, and coordinate a fix before public disclosure.
